# SafeTails: Stray Animal Rescue Management System
A PHP & MySQL web application to manage stray animals, volunteers, rescues, adoptions, and medical records. Includes an admin panel with full CRUD functionality and a sample database for testing.
## Features
- **Animal Management** – Add, update, and view animal details.  
- **Rescue Tracking** – Record rescues with dates and locations.  
- **Volunteer Management** – Manage volunteer information.  
- **Adoption Tracking** – Keep track of adoptions and adopters.  
- **Medical Records** – Log diagnoses, treatments, and vet details.  
- **Admin Panel** – Simple, clean interface for managing all records.
## Technologies Used
- PHP  
- MySQL  
- HTML / CSS  
- XAMPP / phpMyAdmin  
## Getting Started
1. **Clone the repository**
git clone https://github.com/Sakshu-21/stray_animal_rescue.git
2. Start XAMPP and ensure Apache and MySQL are running.

3. Import the database

4. Open phpMyAdmin: http://localhost/phpmyadmin/

5. Create a new database named animal_rescue.

6. Go to the Import tab, select animal_rescue.sql, and click Go.

7. Place the project in htdocs

8. Folder path: C:\xampp\htdocs\stray_animal_rescue

9. Open in browser

10. Visit: http://localhost/stray_animal_rescue/index.php
